Симетричне шифрування (Symmetric Encryption)

Симетричне шифрування — це криптографічний метод захисту даних, у якому для зашифрування відкритого тексту (Plaintext, M) та розшифрування шифротексту (Ciphertext, C) використовується один і той самий секретний ключ (K), відомий обом сторонам обміну:

Зашифрування: C = EK(M) Розшифрування: M = DK(C)

У цьому застосунку для захисту облікових даних у LocalStorage використано симетричний підстановковий шифр ROT13 (модифікований шифр Цезаря зі зсувом на 13 позицій для латинських літер та на 5 позицій для цифр). Оскільки латинський алфавіт містить 26 літер, повторне застосування функції encodeToRot13() повертає початковий текст.

Результат шифрування...
function encodeToRot13(str) {
    const originalAlpha = 'abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789';
    const cipher = 'nopqrstuvwxyzabcdefghijklmNOPQRSTUVWXYZABCDEFGHIJKLM5678901234';
    return str.replace(/[A-Za-z0-9]/g, (letter) => cipher[originalAlpha.indexOf(letter)]);
}
